# RaiCore.Pdf

An open-source (Apache-2.0) .NET library that creates PDF documents: from HTML and CSS, from Razor components, or
from code. It has its own layout engine, so there is no browser to install or run, and the output is the same on
every machine and in every container.

[!code-csharp[](snippets/GettingStarted.cs#html-to-pdf)]

- **[Getting started](guides/getting-started.md)**: install, convert HTML, options, streams, drawing.
- **[Guides](guides/css-support.md)**: CSS support, paged media (headers, footers, page numbers), fonts, images,
  tables and pagination, flexbox, Razor and ASP.NET Core, the layout API, PDF/A and accessibility.
- **[Migration guides](migration/README.md)** from wkhtmltopdf, Puppeteer/Playwright, IronPDF, Aspose and SelectPdf.
- **[API reference](api/RaiCore.Pdf.Html.HtmlToPdf.yml)**, generated from the XML documentation.
- **[Samples](https://github.com/raicevic/raicore-pdf/tree/main/samples)**: runnable apps for typical jobs.

Every code sample in these pages is compiled and run in CI.
