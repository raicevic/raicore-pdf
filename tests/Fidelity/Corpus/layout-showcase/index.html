Floats, text wrap and flex in one flow

Pages per month, January to May

Documents produced by business systems tend to combine a handful of layout techniques: blocks of running text, tables of figures, side-by-side boxes, and the occasional figure that text flows around. This page combines them so that differences in any one of them show up in the comparison.

“Layout bugs hide where techniques meet.”

Text next to a float must shorten its lines and then return to the full width once it passes the bottom of the float. Line heights, the space between paragraphs and the exact position where each line breaks all depend on font metrics, so the fonts are loaded from the same files in both renderers. Words such as display: flex in a monospaced face change the line height slightly, which is another place where small differences add up.

Below the floats, a flex row divides the width into equal columns. Each column holds a short heading and a list. The callout at the end uses a dashed border with rounded corners, a circular icon made with a border radius, and vertical centering with align-items.
